# Laptop Land — Frontend (React + Tailwind + GSAP)

## المتطلبات
- Node.js 18+

## الإعداد

```bash
npm install
cp .env.example .env
```

## التشغيل

```bash
npm run dev
```

الموقع يشتغل على `http://localhost:3000`

## البناء للإنتاج

```bash
npm run build
```

## ملاحظة

تأكد من تشغيل الـ Backend على `http://localhost:8000` أو عدّل `VITE_API_BASE_URL` في `.env`
